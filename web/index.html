Enterprise Workspace

Quản trị TFTP server
trong một màn hình.

Đăng nhập bằng tài khoản Workspace để quản lý tệp, theo dõi phiên truyền, phân quyền người dùng và cấu hình PXE theo đúng vai trò.

  • File Manager với kiểm tra SHA-256
  • Dashboard metrics & Packet Analyzer
  • Phân quyền SUPER_ADMIN, HR, EMPLOYEE…

Đăng nhập Workspace

Sử dụng tài khoản do quản trị viên server cấp.

Tài khoản SUPER_ADMIN đầu tiên được tạo từ TFTP_SUPER_ADMIN_PASSWORD (hoặc TFTP_ADMIN_PASSWORD) khi Workspace chưa có người dùng.
