RFC 1350: truyền file từng khối 512 byte, gửi DATA rồi chờ ACK

Điều khiển

Giả lập sự cố
RRQ / WRQ: yêu cầu đọc / ghi
DATA: khối dữ liệu
ACK: xác nhận
ERROR: báo lỗi

Sơ đồ trao đổi gói tin

Client Cổng 50000 Trạng thái IDLE
Server Cổng 69 Trạng thái LISTEN

Chọn Tải file về hoặc Tải file lên để bắt đầu. Bấm vào một gói tin trên sơ đồ để xem từng byte.
